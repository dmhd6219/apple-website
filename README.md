# Apple Website

A clone of Apple Website with showcase of iPhone 15 Pro. Made with React, TailwindCSS, Three.JS, and GSAP.

## Deployment

A deployed version is available [here](https://dmhd6219-yabloko.netlify.app/).

## Local launch

### 1. Clone Repository

```
git clone https://github.com/dmhd6219/apple-website.git
cd apple-website
```

### 2. Install dependencies

```
npm install
```

### 3. (Optional) Get Yandex Metrika Counter ID

Register a counter in [Yandex Metrika Website](https://metrika.yandex.ru/). Then create a `.env.local` file and past it there:

```
VITE_YM_COUNTER_ID=<YOUR COUNTER>
```

### 4. Launch

Run this command in terminal:

```
npm run dev
```

And then open website at http://127.0.0.1:5173/
